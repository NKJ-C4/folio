# Nishant Kumar Jha portfolio

This is a static, single-file website. No npm install or build step is required.

## Render Static Site

Push index.html to the root of the Git repository linked to your existing Render Static Site. In Render settings, set Publish Directory to `.`. If a Build Command is required, use `echo 'Static site ready'`. Push to the branch configured in Render to deploy automatically, or use Manual Deploy > Deploy latest commit.

If the existing service is a Web Service rather than a Static Site, create a Static Site connected to the repository and move the custom domain after verifying it. Its current start command cannot serve this file by itself.

Edit index.html to update copy, links, colors, and layout. Review figures and the voice bot description before publishing publicly.
